# Green.kz

Банк, төлемдер, аударымдар, кредит және дүкен бір жерде жиналған демо супер-қосымша. Дизайны ашық жасыл түсте.

> Бұл оқу (демо) жобасы: нағыз ақша, банк немесе сервер жоқ. Барлық дерек тек телефонның өзінде сақталады.
> Кредит өтініміне нағыз ЖСН енгізудің қажеті жоқ, кез келген 12 сан жарайды.

## Samsung A53-ке (немесе кез келген Android 6.0+ телефонға) орнату

1. Телефоннан мына сілтемені ашыңыз:
   **[Green-kz.apk жүктеу](https://github.com/Nurgali01/demorepo/raw/claude/kaspi-credit-app-ab2bku/green-kz/Green-kz.apk)**.
   Chrome «файл зиянды болуы мүмкін» деп ескертсе, **«Бәрібір жүктеу»** (Всё равно скачать) батырмасын басыңыз.
2. Жүктелген файлды ашыңыз. Оны хабарландырудан немесе **Менің файлдарым → Жүктеулер** (Мои файлы → Загрузки) бөлімінен табасыз.
3. Телефон «белгісіз көзден орнатуға болмайды» десе, **Параметрлер** батырмасын басып,
   осы көзге (Chrome немесе «Менің файлдарым») рұқсат беріңіз (Разрешить из этого источника).
4. **Орнату** (Установить) батырмасын басыңыз. Play Protect ескерту көрсетсе:
   **Толығырақ → Бәрібір орнату** (Подробнее → Всё равно установить).
5. Қолданбалар тізімінен **Green.kz** иконкасын тауып, ашыңыз.

Орнату мүлдем бұғатталса, Samsung-тың «Автоблокировщик» функциясын уақытша өшіріңіз:
**Параметрлер → Қауіпсіздік және құпиялылық → Автоблокировщик** (Безопасность и конфиденциальность → Автоблокировщик).

## Мүмкіндіктер

- **Басты бет:** баланс (жасыруға болады), сторис, 8 сервистің мәзірі, Green Кредит баннері, соңғы операциялар, сервис іздеу.
- **Менің банкім:** карта, шоттар, кредиттер, операциялар тарихы, шотты толтыру.
- **Төлемдер және аударымдар:** мобильді байланыс, коммуналдық төлемдер, интернет, айыппұлдар; телефон немесе карта нөмірі бойынша аудару.
- **Green Кредит:** калькулятор (аннуитетті / сараланған), төлем кестесі, өтінім беру және демо-скоринг (ай сайынғы төлем табыстың 50%-ынан аспауы керек).
- **Green Дүкен:** тауарлар және 12 айға бөліп төлеу.
- **Басқалары:** QR төлем, депозит калькуляторы, хабарламалар, профиль.

## Құрылымы

| Файл | Мақсаты |
| --- | --- |
| `index.html`, `styles.css`, `app.js` | Веб-қосымша. `index.html`-ді браузерде де ашуға болады |
| `android/` | Android қабығы (WebView), иконкалар және `build-apk.sh` жинау скрипті |
| `Green-kz.apk` | Дайын орнату файлы |

## APK-ны қайта жинау (Ubuntu/Debian)

```bash
sudo apt-get install openjdk-17-jdk-headless android-sdk-platform-23 aapt zipalign apksigner dalvik-exchange zip
bash green-kz/android/build-apk.sh
```

Қол қою кілті `~/.android/green-kz.jks` файлында жасалады және репоға кірмейді.
Жаңа нұсқа басқа кілтпен жиналса, оны орнатар алдында телефондағы ескі Green.kz-ті өшіріп тастаңыз.
