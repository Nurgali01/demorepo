# Green.kz

Банк, төлемдер, аударымдар, кредит, дүкен және цифрлық құжаттар бір жерде жиналған демо супер-қосымша. Дизайны ашық жасыл түсте.

> Бұл оқу (демо) жобасы: нағыз ақша, банк немесе сервер жоқ. Барлық дерек тек телефонның өзінде сақталады.
> Кредит өтініміне нағыз ЖСН енгізудің қажеті жоқ, кез келген 12 сан жарайды.

## Samsung A53-ке (немесе кез келген Android 6.0+ телефонға) орнату

1. Телефоннан мына сілтемені ашыңыз:
   **[Green-kz.apk жүктеу](https://github.com/Nurgali01/demorepo/raw/claude/kaspi-credit-app-ab2bku/green-kz/Green-kz.apk)**.
   Chrome «файл зиянды болуы мүмкін» деп ескертсе, **«Бәрібір жүктеу»** (Всё равно скачать) батырмасын басыңыз.
2. Жүктелген файлды ашыңыз. Оны хабарландырудан немесе **Менің файлдарым → Жүктеулер** (Мои файлы → Загрузки) бөлімінен табасыз.
3. Телефон «белгісіз көзден орнатуға болмайды» десе, **Параметрлер** батырмасын басып,
   осы көзге (Chrome немесе «Менің файлдарым») рұқсат беріңіз (Разрешить из этого источника).
4. **Орнату** (Установить) батырмасын басыңыз. Play Protect ескерту көрсетсе:
   **Толығырақ → Бәрібір орнату** (Подробнее → Всё равно установить).
5. Қолданбалар тізімінен **Green.kz** иконкасын тауып, ашыңыз.

Орнату мүлдем бұғатталса, Samsung-тың «Автоблокировщик» функциясын уақытша өшіріңіз:
**Параметрлер → Қауіпсіздік және құпиялылық → Автоблокировщик** (Безопасность и конфиденциальность → Автоблокировщик).

**Жаңарту.** Жаңа нұсқаны да дәл осылай жүктеп, ескісінің үстінен орнатыңыз: деректер (код, құжаттар, баланс) сақталады.
Қосымшаны өшіріп тастамаңыз, әйтпесе оның ішіндегі деректер де өшеді.

## Мүмкіндіктер

- **Кіру коды.** Қосымшаға кіргенде 4 санды код сұралады (алғаш ашқанда оны өзіңіз ойлап табасыз).
  Қосымша ішінде жүргенде код қайта сұралмайды. Қосымшадан шығып, **10 секунд ішінде** қайта кірсеңіз де сұралмайды.
  5 рет қате терсеңіз, 30 секунд күту керек (әр келесі 5 қатеден кейін уақыт екі еселенеді).
- **Саусақ ізі және бет тану.** Кодтың орнына Android-тың жүйелік биометрия терезесі арқылы кіруге болады.
  Профиль → Қауіпсіздік бөлімінен қосылады немесе өшіріледі.
- **Мемлекеттік қызметтер → Цифрлық құжаттар.** Жеке куәлік, жүргізуші куәлігі, диплом, әскери билет және
  мекенжай анықтамасы (прописка) PDF күйінде жүктеледі (бір файл 25 МБ-қа дейін) және қосымша ішінде ашылады:
  беттерді айналдыру, үлкейту (100–300%, екі рет түрту), құпиясөзбен қорғалған PDF-ті ашу. Файлды ауыстыруға және өшіруге болады.
- **Басты бет:** баланс (жасыруға болады), сторис, 8 сервистің мәзірі, Green Кредит баннері, соңғы операциялар, сервис іздеу.
- **Менің банкім:** карта, шоттар, кредиттер, операциялар тарихы, шотты толтыру.
- **Төлемдер және аударымдар:** мобильді байланыс, коммуналдық төлемдер, интернет, айыппұлдар; телефон немесе карта нөмірі бойынша аудару.
- **Green Кредит:** калькулятор (аннуитетті / сараланған), төлем кестесі, өтінім беру және демо-скоринг (ай сайынғы төлем табыстың 50%-ынан аспауы керек).
- **Green Дүкен:** тауарлар және 12 айға бөліп төлеу.
- **Профиль:** атыңызды және телефон нөмірін өзгерту, кіру кодын өзгерту, қосымшаны бірден құлыптау.
- **Басқалары:** QR төлем, депозит калькуляторы, хабарламалар.

## Қауіпсіздік туралы маңызды ескертулер

- **Бет тану телефонға байланысты.** Қосымша Android-тан «биометриямен растауды» сұрайды, ал саусақ ізін бе, бетті ме —
  оны телефон шешеді. Кейбір Samsung үлгілерінде бет тану тек экранды ашуға арналған және қосымшаларға берілмейді;
  ондай жағдайда жүйелік терезеде тек саусақ ізі шығады. Саусақ ізі де, бет те тіркелмесе, тек код қолданылады.
- **Кодты ұмытсаңыз, оны қалпына келтіру мүмкін емес** (сервер жоқ). «Кодты ұмыттыңыз ба?» батырмасы жаңа код орнатуға
  мүмкіндік береді, бірақ қосымшадағы барлық дерек (баланс, тарих, құжаттар) өшіріледі.
- **Құжаттардың түпнұсқасын сақтаңыз.** Қосымша PDF-тің көшірмесін өз жеке қоймасында ұстайды. Қосымшаны өшірсеңіз немесе
  Android параметрлерінен «Деректерді тазалау» жасасаңыз, көшірмелер де өшеді.
- **Бұл — экран құлпы, шифрлау емес.** Код ашық түрде сақталмайды (тұз + PBKDF2-SHA256 хэші), бірақ құжаттардың өзі
  шифрланбайды: оларды басқа қосымшалардан Android-тың өзі қорғайды. Бұлттық сақтық көшірме өшірілген, файлдар ешқайда жіберілмейді.

## Құрылымы

| Файл | Мақсаты |
| --- | --- |
| `index.html`, `styles.css` | Бет қаңқасы мен стильдер |
| `app.js` | Экрандар, навигация, банк/кредит/дүкен логикасы, профиль, құжаттар тізімі |
| `lock.js` | Кіру коды, биометрия, «10 секунд» ережесі |
| `docs.js` | Құжаттар қоймасы (IndexedDB) және PDF қарау терезесі |
| `vendor/pdfjs/` | [PDF.js](https://github.com/mozilla/pdf.js) 4.10.38 (Mozilla, Apache-2.0) — PDF беттерін салады |
| `android/` | Android қабығы (WebView), биометрия көпірі, иконкалар және `build-apk.sh` жинау скрипті |
| `Green-kz.apk` | Дайын орнату файлы |

`index.html`-ді браузерде де ашуға болады: бәрі жұмыс істейді, тек биометрия жоқ (ол Android қосымшасында ғана бар).

## APK-ны қайта жинау (Ubuntu/Debian)

```bash
sudo apt-get install openjdk-17-jdk-headless android-sdk-platform-23 aapt zipalign apksigner dalvik-exchange zip
bash green-kz/android/build-apk.sh
```

Қол қою кілті `~/.android/green-kz.jks` файлында жасалады және репоға кірмейді.
Жаңа нұсқа басқа кілтпен жиналса, Android оны ескісінің үстінен орнатпайды: алдымен ескі Green.kz-ті өшіру керек болады
(бұл кезде қосымшадағы деректер де өшеді).

`android/stubs/` — тек компиляцияға керек шағын файлдар: `build-apk.sh` Android 6 кітапханасымен жинайды, ал онда
кейін қосылған `BiometricPrompt` жоқ. Олар APK-ға кірмейді; телефонда нағыз жүйелік кластар қолданылады.

<details>
<summary>PDF.js жинағы қалай жасалған</summary>

`file://` бетінде және Android WebView-та ES модульдері мен Web Worker жүктелмейді, сондықтан `pdfjs-dist` пакетінің
legacy жинағы esbuild арқылы кәдімгі скриптке айналдырылған (PDF беттері негізгі ағында салынады):

```bash
npm i pdfjs-dist@4.10.38 esbuild
npx esbuild node_modules/pdfjs-dist/legacy/build/pdf.min.mjs --bundle --minify --format=iife \
  --global-name=pdfjsLib --platform=browser --legal-comments=inline --outfile=vendor/pdfjs/pdf.min.js
npx esbuild node_modules/pdfjs-dist/legacy/build/pdf.worker.min.mjs --bundle --minify --format=iife \
  --global-name=pdfjsWorker --platform=browser --legal-comments=inline --outfile=vendor/pdfjs/pdf.worker.min.js
```

</details>
